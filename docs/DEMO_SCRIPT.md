# CloudReady AI — 3-Minute Demo Script

## Before recording

- Open the production URL and sign in with an email-confirmed account.
- Ensure at least one saved quiz session exists so dashboard/review aren't empty.
- Close unrelated tabs and notifications.
- Test the full flow once before recording.
- Never show `.env.local`, Supabase keys, email tokens, or private user data.
- Confirm the video link works in a private/incognito window.

## 0:00–0:25 — Problem

“Preparing for AZ-900 is not just about memorizing cloud terms. Learners need to know whether they understand a concept, why an answer is correct, and what to revisit after a mistake. I built CloudReady AI around that practice loop.”

## 0:25–0:45 — Solution

“CloudReady AI is a focused AZ-900 practice and assessment prototype. It organizes practice around exam topics and emphasizes feedback, explanations, and a way to revisit mistakes.”

Show the homepage.

## 0:45–1:35 — Core quiz

Open a quiz, read one question, select an answer, and pause so the judges can see the feedback/explanation. Complete the quiz or show a completed session if time is short.

“The goal is not only to mark an answer right or wrong. The explanation helps the learner understand the reasoning and learn from a wrong choice.”

## 1:35–2:10 — Progress and review

Show the dashboard, then Review with a missed question, selected answer, correct answer, and explanation.

“After practice, learners can see how they performed and return to questions they missed. This connects assessment with revision.”

## 2:10–2:35 — Implementation and AI assistance

“CloudReady AI uses React, TypeScript, and Vite for the frontend, Supabase for authentication and cloud-stored quiz sessions, and Vercel for deployment. I used AI-assisted iterative development because my access to hosted low-code builder credits was limited. I focused on small changes, build checks, and manual verification.”

## 2:35–3:00 — Impact and close

“The first target users are beginners, students, and career-switchers preparing for Azure Fundamentals. The approach can scale through better question coverage, verified explanations, accessibility improvements, and eventually other certification tracks. CloudReady AI is an independent study aid, not an official Microsoft product or a guarantee of passing.”

## Recording notes

- Follow the event's video-duration rules.
- Use a public or unlisted video link if the event permits it.
- Do not claim formal user testing, improved pass rates, or runtime AI question generation unless you have evidence and the feature exists.
